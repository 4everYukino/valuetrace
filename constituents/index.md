# 国证成长 100 成分股

归档国证成长 100（980080）的成分股名单，目录按调样生效日**所在季度**命名。

> [国证指数官网](https://www.cnindex.com.cn/module/index-detail.html?indexCode=980080)

## JSON

顺序沿用官网样本。

四个字段也直接沿用官网样本即可:

* `date`
* `code`
* `name`
* `industry`

## Markdown

以季度命名，如 `26Q4.md`，依次展示沪深主板、科创板、创业板、北交所。各板块内沿用官网样本顺序，无样本的板块标明「本期无样本」。

除了 JSON 中的四个字段外，表格中多一个拓展字段「是否已分析」，若尚无报告则填「否」，若已有分析报告则链接到仓库中的报告。
